What the width buys you

At a full 14-inch or larger screen the console runs three columns: the section rail, the property list, and the open record. Selecting a property never replaces what you were looking at, so you can walk the list without losing your place.

The two cards stack in the record pane — the local card raised and solid because it is who you actually call, the master card set back behind a dashed rule because it is inherited from the region above and shared with five sister properties.

Same layout, tighter

A standard Windows laptop is the most common screen this will actually run on. It holds the same three columns with roughly 240 fewer pixels, so nothing reflows and nothing is hidden — the columns just narrow.

Type is set in points that hold up at 1× density, which is where Windows text usually gets thin. The mono column used for phone numbers and email is tabular, so the reach column stays in a straight edge instead of ragging.

What changes below 760px

The rail stops being a rail. It becomes a scrolling tab strip pinned to the top of the screen, so switching sections never means scrolling back up — and it opens already scrolled to wherever you are.

The three columns fold into one: filters, then the property list, then the open record beneath it. Search and Add lead share a row and stay reachable with a thumb.

Android at the same 390-point class renders identically; the frame around this one is cosmetic.

The console never picks a theme for you. It reads the machine's setting, and the Switch theme control in the rail overrides it per device — so the same account can be dark on a desk and light on a phone.

The rules underneath

≥ 1080px
Three columns. Rail, list, record. The record pane never covers the list.
760–1080px
Two columns. The rail holds; list and record stack in the remaining width.
< 760px
One column. The rail becomes a top tab strip; everything else stacks in reading order.
type
One scale across all three. Nothing shrinks on mobile — the layout gives way instead of the text.
tables
Anything wider than the column scrolls inside its own card. The page itself never scrolls sideways.
motion
Every transition is off when the machine asks for reduced motion.
